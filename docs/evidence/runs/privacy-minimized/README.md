## Hard rule

This file records **only** file locations, line numbers, categories and
generic context. The matched path values are **not** copied, quoted or
reproduced anywhere in this file, in any successor, test fixture or
report. Classification used redacting probes: matched values were
replaced before inspection, and attribution was decided from structural
properties only.

## What a successor is — and is not

A file in this directory is a **minimized, provenance-linked successor**
of a registry-bound evidence artifact. It carries the same evidence
values except for the minimized field, and it records its source below.
It is **not** the original artifact: its digest is **not** the digest
bound by the claims gate (`docs/evidence/registry.json`, U7(b)) and it
must never be cited as the original, registered in the registry, or
substituted for the original in any claim. The originals remain the
evidence of record, byte-identical, in `docs/evidence/runs/`.
